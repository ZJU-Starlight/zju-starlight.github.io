## 什么是markdown，以及为什么选择markdown

markdown是一种**轻量级标记语言**，能够以特定的符号描述文档的结构和格式（例如以`# `开头可以把本行标记为一级标题）。

WPS文字、Office word相信大家用得很多。这类软件编辑文本时“所见即所得”，但在写作时，需要频繁用鼠标设置文档的格式、且时长由于段落、缩进、字体的综合引发各种bug。

markdown是“标记语言”，文档的格式是直接用字符写在文档里的，在写作的同时就能写好文档的格式。此外，由于markdown语法很受程序员的欢迎，他们开发了有许多对markdown文档有特别支持的软件——你可以用markdown语法画思维导图、做ppt、写个人博客（比如本网站）······因此只需要简单涉猎markdown语言，就相当于拿到了一把多功能工具箱的钥匙。此外，大语言模型对markdown语言的支持度也很好。

我们社团之所以会推行markdown语言作为内训项目，

一方面这个东西确实具有跨专业的实用性，另一方面我们的一些项目会用到markdown语言，需要保证加入社团的新鲜血液有维护和更新的能力。

## obsidian简介

obsidian的定位是一款笔记软件；其拥有丰富的第三方插件，实现多种高级功能，例如渲染思维导图、创建时间戳、创建白板、更改界面主题等；

此外，即使不依赖第三方插件，其本体也具有“即时渲染”功能，能立刻渲染出格式，对第一次接触markdown文档的用户比较友好。而且它的markdown文档还支持插入latex数学公式——相比在word中插入和编辑公式，在markdown文档中插入、编辑公式要更加准确

[点击访问obsidion官网](https://obsidian.md/)，更多有关obsidion的介绍，可以阅读obsidion官方用户手册和社区帖子
