# 天璇：外联与运营

让外校幻迷和校内社团与星弦联系起来，一起把合作变成活动。

## 主要职责

- 联系外校科幻爱好者与本校其他社团。
- 筹备合作事项。
- 处理对外活动的行政事务。

具体联系人和合作安排见[本学期负责人及分工](../../club/contacts.md)。

## 合作活动怎么配合

筹备合作时，先和对方及协会负责人确认活动内容、各方分工与时间安排。涉及财务、物料时与[天玑](finance.md)协作；涉及微信公众号、CC98 宣传时与[开阳](publicity.md)协作；涉及 B 站或技术项目时与[玉衡](technology.md)协作。

[天权](events.md)负责校内活动的策划、实施与善后。共同举办的活动可以按具体任务分工，干员在统筹协调下跨部门参与。

- [日常管理与换届交接](../handover.md)：记录决定、待办和资料去向。
