# 天玑：财务与物料

图书在哪里，物料还剩多少，活动的报销走到哪一步——这些是天玑负责的事情。

## 主要职责

- **图书统计**：组织协会图书的清点与统计。
- **物料统计**：组织活动物料的清点与统计。
- **财务报销**：负责协会财务与报销流程。

对外活动的行政事务由[天璇](outreach.md)负责；校内活动的策划、实施和善后由[天权](events.md)负责。活动中的经费和物料工作与天玑协作。

## 接到任务后，从哪里看起

| 任务 | 资料入口 |
| --- | --- |
| 查预算、采购、报销和物资管理资料 | 经费与物资（草稿，暂未发布） |
| 了解活动材料如何准备和交付 | [活动全流程](../activities.md) |
| 查找空白表格与正式规则 | [文件与模板](../templates/index.md) · 制度与校方文件（草稿，暂未发布） |

最新报销规则、台账和具体经办人仍需由当届负责人提供，见[本学期分工](../../club/contacts.md)。
