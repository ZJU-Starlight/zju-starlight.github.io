# 日常管理与换届交接

把日常决定、工作进展和资料去向记录下来，方便接续工作。

## 日常记录

| 事项 | 建议记录的内容 | 当前状态 |
| --- | --- | --- |
| 例会与项目会议 | 日期、议题、结论、待办、负责人、截止时间 | 纪要模板与存放入口待补充 |
| 招新与内训 | 招募安排、培训内容、负责人、学习资料 | [干员问卷](../club/join.md)可填写；每周晚间内训的具体场次待群通知 |
| 学期总结 | 活动清单、成果、问题与下学期建议 | 总结模板待补充 |
| 换届交接 | 接收人、资料位置、权限、物资、未完成事项 | 实际交接安排待补充 |

## 部门之间怎么协作

在统筹协调下，干员可以根据兴趣和实际工作需要参与不同方向。分工时先说清楚这次要做的事，再确认参与人。

每周晚间内训教授社团工作需要的技能。具体日期、地点与课程以群通知为准，培训资料可以接到[骨干手册](index.md)对应的指南下。

[查找部门分工](../club/contacts.md)。

## 交接清单框架

- [ ] 确认各项事务的交出人与接收人。
- [ ] 整理进行中的活动、已承诺事项和截止日期。
- [ ] 交接网站、媒体、协作空间和网盘的管理权限。
- [ ] 清点物资，核对借还和未完成的经费事项。
- [ ] 整理当学期活动记录、会议纪要与工作总结。
- [ ] 更新[本学期负责人](../club/contacts.md)，将旧名单收录到[历届档案](../archive/records.md)。

具体交接方式由当届负责人确认；密码、验证码和恢复密钥不写入公开交接记录。
