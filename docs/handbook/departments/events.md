# 天权：校内活动

从一个活动点子开始，把策划、现场和善后接起来。

## 主要职责

- 负责校内活动的策划与流程。
- 实施活动，并完成后续善后。
- 延续已有品牌活动，也尝试创造新活动。

协会以科幻文学、科幻影视、科幻游戏为活动方向。征文、读书会、沙龙、观影等已有例子见[认识星弦](../../club/index.md)；具体活动安排见[本学期日程](../../events/calendar.md)。

## 从筹备到结项

| 阶段 | 资料入口 |
| --- | --- |
| 确认活动内容、时间和分工 | [活动全流程](../activities.md) · [岗位职责与协作](../roles.md) |
| 准备计划书、场地与物料 | [活动计划书](../templates/proposal.md) · [借教室](../venues.md) · 经费与物资（草稿，暂未发布） |
| 宣传、实施与记录 | [宣传与媒体](../publicity.md) · [活动举办](../activity-guide.md) |
| 完成善后和留档 | [结项与二课分](../closing.md) · [活动档案](../../archive/records.md) |

活动所需的财务与物料工作可以与[天玑](finance.md)配合，微信公众号和 CC98 宣传与[开阳](publicity.md)配合，技术及 B 站内容与[玉衡](technology.md)配合。涉及对外合作时联系[天璇](outreach.md)。

部门可以在统筹协调下灵活调整。每次活动先确认项目负责人和实际任务，再组织参与人。
