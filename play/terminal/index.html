    使用说明与资料来源

    每次进入终端，须先输入自己的 DeepSeek API Key；完成接入后，本页会话中无需重复输入。API Key 的有效性在首次聊天时由服务商确认。掷骰和灯谜在进入终端后由本地程序处理，不产生 AI 请求。

    输入“掷骰 3d6”可投掷三颗六面骰，支持 1–100 颗、每颗 2–1,000,000 面。灯谜支持“提示”“答案”“下一题”和“退出灯谜”，也可直接点击面板按钮。终端灯谜进度仅保留到离开页面，不影响科幻灯谜专页的存档。

    异常剧情属于虚构。社团咨询和办事查询使用原终端 v1.7 的资料快照（2026-10-05 提取），不代表信息已更新或核验；最新安排请查看活动公告和办事手册。重启会清空对话与本轮灯谜，保留本页已输入的凭据；断开会清除凭据并返回认证页。离开或刷新页面后需重新接入。
