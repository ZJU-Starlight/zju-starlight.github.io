## 发布通知

准备通知时，可以使用[通用通知模板](../handbook/templates/notice.md)，并参考[宣传与媒体](../handbook/publicity.md)。通知应写明需要读者做什么、何时完成、在哪里参与、向谁咨询。

时间或地点发生变化时，请同步更新原通知，并保留变更说明。
