# 开阳：文字与宣传

写自己的故事，也把协会的活动讲给更多人听。开阳包括写作组、共创项目，以及微信公众号和 CC98 官号运营。

## 创作与共创

写作组和共创项目是开阳的两个方向。想看已有作品，可以从本站的[星途所档案](../../archive/universe/index.md)读起；想了解征文、作品结集和练笔活动，可以查[学年回顾](../../archive/annual/2025-2026.md)。

“星途所”共创企划正在筹划重建，具体启动安排见[本学期活动计划](../../events/calendar.md)。已有故事与新企划的筹备进度分别留档。

## 宣传与账号运营

- **微信公众号**：准备文案与排版，发布活动信息及相关内容。
- **CC98 官号**：发布和维护协会的论坛内容。
- **活动宣传**：与活动项目组配合，把准确、清楚的活动信息做成推文和宣传品。

B 站账号由[玉衡](technology.md)运营。不同平台发布前，需核对活动名称、日期、地点、参与方式和链接是否一致。
