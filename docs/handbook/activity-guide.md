# 活动举办

先阅读[活动全流程](activities.md)，确认本次活动涉及哪些环节，再进入对应指南。

[天权](departments/events.md)负责**校内活动的策划、实施与善后**，[天璇](departments/outreach.md)负责**对外合作及对外活动行政事务**。每场活动按实际任务组织项目组，与天玑、玉衡、开阳等部门配合。

## 按环节查找

| 环节 | 要明确的事情 | 指南与资料 |
| --- | --- | --- |
| 策划与分工 | 活动内容、时间地点、人员和工作量 | [活动全流程](activities.md)、[岗位职责](roles.md) |
| 计划书与立项 | 所需材料、申请渠道和审核要求 | [活动计划书](templates/proposal.md)、制度与校方文件（草稿，暂未发布） |
| 场地与准备 | 场地是否落实、人员与物料是否到位 | [借教室](venues.md)、经费与物资（草稿，暂未发布） |
| 宣传与报名 | 面向对象、报名方式、截止时间 | [宣传与媒体](publicity.md)、[通知模板](templates/notice.md) |
| 现场执行 | 主持、签到、拍照、秩序与奖品发放 | [活动全流程](activities.md) |
| 结项与整理 | 二课分、材料交付、总结与归档 | [结项与二课分](closing.md)、[活动档案](../archive/records.md) |

## 筹备前确认

- 谁是活动负责人，哪些任务由哪些人完成？
- 哪些日期已经确认，哪些仍是计划？
- 是否需要申请场地、经费、宣传资源或二课分？
- 用哪些模板，活动结束后需要交付哪些材料？

## 仍待补充

立项平台的具体操作、现场岗位清单、活动变更或取消的处理方式，以及不同类型活动的结项要求。
