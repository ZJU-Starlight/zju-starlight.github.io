# 通用通知模板

适用于活动报名、会议、材料提交与安排变更。复制下方正文，替换方括号中的内容，删除不适用的项目。

```markdown
# [通知标题]

发布日期：[YYYY-MM-DD]
面向对象：[谁需要阅读或参与]
状态：[报名中／进行中／已结束／已取消]

## 需要做什么

[用一两句话说明事项和读者需要采取的行动。]

## 时间与地点

- 举办时间：[完整日期及时间；不适用则删除]
- 截止时间：[完整日期及时间；无截止时间请注明]
- 地点或参与方式：[场地、线上方式或报名入口]

## 参与或提交要求

[填写资格、步骤、材料、命名方式和提交渠道。]

## 附件与联系

- 附件：[文件名称、版本及有效链接；无附件则删除]
- 负责人：[公开称呼]
- 咨询方式：[社团工作邮箱或公开联系入口]

## 变更记录

[如有调整，注明更新时间、变更内容与最终安排；无变更则删除。]
```

发布前核对所有日期、链接、附件和联系入口；在[通知公告](../../events/index.md)中登记通知。发布方法见[网站文章发布](../website/publishing.md)。
