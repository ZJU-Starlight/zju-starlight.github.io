## 按部门了解工作

五个干员部门的职责和工作入口如下：

| 部门 | 主要方向 |
| --- | --- |
| [天璇](departments/outreach.md) | 外联、合作与对外活动行政事务 |
| [天权](departments/events.md) | 校内活动的策划、实施和善后 |
| [天玑](departments/finance.md) | 财务、图书与物料管理 |
| [玉衡](departments/technology.md) | 技术小组、独立游戏工作室与 B 站运营 |
| [开阳](departments/publicity.md) | 写作、共创与微信公众号、CC98 官号运营 |

天枢是社长层，摇光是普通社员。干员可以在统筹协调下灵活调整所属部门，每周晚间内训的具体安排以群通知为准。[报名成为干员](../club/join.md)。

## 第一次承担工作

1. 在[本学期安排](../events/semester.md)中找到对应负责人，确认任务、交付物和时间。
2. 按任务阅读相应指南，并从[资料中心](resources.md)获取模板。
3. 完成后交付成果，按活动或学期整理记录，供下一次工作参考。

## 内容状态

活动流程、借教室、推文与网站维护已有文章；结项、经费、物资及交接等栏目目前提供整理框架，具体操作仍待负责人补充。涉及学校平台的旧指南，请结合适用学期和原始文件核验。

近期通知和具体日程请查[主页](../index.md)；历届名单和活动记录请查[档案](../archive/records.md)。
