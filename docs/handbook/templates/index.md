# 文件与模板

优先使用空白模板，再参考填写示例。示例中的历史日期、人员、金额和链接需要按实际活动核对。

## 已有模板

| 模板 | 用途 | 使用说明 |
| --- | --- | --- |
| [通用通知模板](notice.md) | 活动报名、会议、材料提交与安排变更 | 复制空白正文并填写必需信息 |
| [活动计划书](proposal.md) | 整理活动内容、预算与安全方案 | 包含历史示例和空白框架 |
| [燃藜活动通知](reading.md) | 阅读活动公告 | 空白模板与历史示例分别使用 |

## 待补充文件

| 文件 | 需要补充的内容 |
| --- | --- |
| 预算与报销表格 | 本学期正式空白文件、填写说明及来源 |
| 签到与领奖表 | 空白表格、适用场景和材料接收人 |
| 会议纪要与活动总结 | 空白模板与可公开的完成示例 |
| 换届交接清单 | 资料、权限、物资和未完成事项的记录模板 |
| 宣传素材 | 头尾图、标识、海报模板及使用说明 |

## 下载与使用

协作文档和大附件的入口尚未提供。接入后，每个文件注明格式、版本日期、维护人和访问方式；多人共同填写的文档应先按说明创建副本。

已填写的活动材料归入[活动档案](../../archive/records.md)，空白模板留在本页供后续活动使用。
