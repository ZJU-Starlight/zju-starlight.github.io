# 指南撰写指南
***我们的智慧需要以浓缩的形式传递下去***

摘要：简要介绍本网站指南的撰写方式与建议

撰写日期 | 2025/9/17

天天开心

## 一篇指南的基本组成部分
1. 名称
2. 楔子：一句无关紧要话，用来提升文章的逼格，比如本篇教程开头那句
	- 特殊格式：加粗斜体
3. 摘要（可选）
4. 撰写日期：评估指南是否过期的主要依据
5. 作者署名
6. 标题和小标题（可选）
7. 正文

## 如何写好一篇指南
1. 明确受众
	- 面向第一次操作的成员，解释入口、术语和必要的准备条件，不假定读者已经熟悉流程。
2. 用语简明扼要
3. 明确区分“推荐设置”和“规范”
4. 优先使用可独立阅读的文字
	- 操作写明菜单和按钮名称；字段要求用表格；命令配示例输出，并说明怎样判断成功。
	- 链接提供官方入口和补充细节，正文仍保留完成任务所需的步骤。
	- 关系或条件分支可以使用 Mermaid，图前提供等价文字。简单步骤直接使用编号列表。
	- 仅在需要观察照片、实物或场地布置时插图，提供有意义的替代文本；不使用“500”或“alt text”作为说明。
5. 遵循排版规则，以保持网站文章格式一致
